# Wenlin Zhang's Homepage

This repository contains the source for <https://wlzhang2020.github.io/>.

The site now uses the Jekyll Minimal Light-style template from <https://zhang-yingyi.github.io/>, adapted for Wenlin Zhang's profile, publications, awards, education, and CV.

## Local Preview

Install Ruby and Bundler first, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open <http://127.0.0.1:4000/> in your browser.

## Main Files

- `_config.yml`: profile metadata, links, avatar, CV, theme options
- `index.md`: homepage sections and news
- `_data/publications.yml`: publication list
- `_data/education.yml`: education list
- `_data/awards.yml`: honors and awards
- `assets/img/avatar.jpg`: profile photo
- `assets/files/WenlinZhang_CV.pdf`: CV file
